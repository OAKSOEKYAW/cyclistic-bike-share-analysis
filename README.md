# Cyclistic-Bike-Share-Analysis
---------------------------------
Data analysis case study of Cyclistic Bike-Share program using SQL and Power BI to identify behavioral differences between annual members and casual riders.

This project was completed as part of the **Google Data Analytics Capstone: Complete a Case Study** course on **Coursera**, fulfilling the final capstone requirement for certification.  
While the company and business objectives in this scenario are fictional, the dataset is real — sourced from the **[Divvy Bikes](https://divvybikes.com/)** bike-sharing program in Chicago.

The dataset used for this cased study is not uploaded to the Github repo because the raw data files exceed GitHub's single-file limit of 100MB but if you wish to download the dataset you can download it from '[City of Chicago’s Divvy Bike Share program](https://divvy-tripdata.s3.amazonaws.com/index.html)'

**Tools used:**  
- MySQL (for data cleaning, transformation, and analysis)  
- Power BI (for visualization and dashboard development)  
- Microsoft Word (for report documentation)

**Objective:**  
To analyze usage patterns and identify actionable insights that help **convert casual riders into annual members**, supporting Cyclistic’s strategic marketing goals.
